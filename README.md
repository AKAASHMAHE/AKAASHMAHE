## 🚀 Featured Projects

### 🛒 Smart Grocery Management System
**Tech Stack:** ESP32, YOLOv8, Python, Blynk, Google Sheets API

- **Problem Solved:** Manual grocery/inventory monitoring is time-consuming and error-prone; this system automates stock tracking and freshness monitoring.
- **Key Features:**
  - Real-time vegetable detection using a camera module powered by YOLOv8
  - Asynchronous data logging to Google Sheets for persistent, real-time record-keeping
  - Automated alerts via Blynk for stock depletion and abnormal environmental conditions
- **My Contribution:** Designed and built the full system — from ESP32/sensor integration to the ML detection pipeline and alerting logic.
- **Future Improvements:** Expand item recognition to more grocery categories; add predictive restocking based on consumption trends.

---

### 🏟️ PlayMate – Sports Scheduling and Ground Management System
**Tech Stack:** Java Servlets, JSP, REST APIs, MySQL

- **Problem Solved:** Coordinating ground bookings and avoiding scheduling conflicts across multiple sports and players.
- **Key Features:**
  - Role-based architecture: REST APIs for Admin, Java Servlets + JSP for Players
  - Concurrency-safe booking mechanism preventing double-booking of grounds
  - Time-slot conflict validation and ground availability checks
  - Normalized relational schema ensuring transactional data integrity
- **My Contribution:** Designed the role-based system architecture and implemented the concurrency-safe booking and validation logic.
- **Future Improvements:** Add payment integration and a notification system for booking confirmations.

---

### 📦 ML-Based Conveyor Belt Sorting System
**Tech Stack:** Python, YOLO, OpenCV

- **Problem Solved:** Automates object sorting on a conveyor belt while improving workplace safety.
- **Key Features:**
  - Real-time object detection and classification using YOLO + OpenCV
  - Worker safety mechanism that detects unsafe proximity to machinery
- **My Contribution:** Designed and deployed the ML-based detection and classification pipeline, including the safety detection layer.
- **Future Improvements:** Extend to multi-class sorting with a robotic arm actuation system.

---

### 🔐 Biometric Voting System
**Tech Stack:** Arduino Uno, Fingerprint Sensor

- **Problem Solved:** Prevents duplicate/fraudulent voting through biometric verification in a low-resource embedded environment.
- **Key Features:**
  - Fingerprint-based authentication ensuring one-person-one-vote
  - Memory-optimized implementation for embedded system constraints
- **My Contribution:** Engineered the complete authentication and voting logic on Arduino Uno.
- **Future Improvements:** Add encrypted vote storage and a tally dashboard.
